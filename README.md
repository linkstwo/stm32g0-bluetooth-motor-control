# STM32G0 蓝牙双电机控制｜ZX-D30 + DRV8837

通过蓝牙发送单字符指令，控制两路直流电机的转向、PWM 占空比档位和平滑变速。源码使用 STM32G0 HAL、ZX-D30 蓝牙串口模块和两路 DRV8837 电机桥，适合阅读或继续开发蓝牙电机调试控制。

原仓库名：`stm32buttfly`。当前已经提交 `Core/` 源码；旧首页中“没有实际程序”的描述已按实际文件更正。

## 工作原理

```text
蓝牙发送端
   ↓ 单字符命令
ZX-D30 → USART1 接收中断 → 字节队列 → 主循环解析
   ↓
占空比渐变与方向控制 → TIM2 / TIM14 PWM → DRV8837 → 两路电机
```

接收中断负责收字节，主循环处理指令并按时间逐步调整占空比。两台电机按相反方向配对运行，可切换方向。这里的“档位”是 **PWM 占空比**，源码没有编码器测速闭环，不能把百分比当成实际转速。

## 已实现的指令

串口配置为 **9600、8N1**；命令区分数字，字母支持大小写。

| 指令 | 代码中的行为 |
| --- | --- |
| `L` | 平滑调到 18% 占空比 |
| `1 / 2 / 3 / 4` | 平滑调到 45% / 75% / 100% / 20% |
| `U` | 低于 70% 时先设为 70%，再逐步升到 100% |
| `-` | 在当前目标基础上降低 1 个百分点 |
| `0 / S` | 平滑降到 0%，随后停止输出 |
| `F` | M1 正向、M2 反向 |
| `R` | M1 反向、M2 正向 |

常规平滑变速按约 800 ms 的目标过渡时间计算步进间隔。达到需要回报的目标占空比时，串口返回 `duty=...%`；具体行为见 [main.c](Core/Src/main.c)。

## 编译与当前状态

仓库目前只包含 `Core/Inc`、`Core/Src` 和 README，**缺少完整 HAL/CMSIS 驱动、启动与链接配置、工程文件和 CubeMX 的 .ioc 文件**，不能按完整工程直接编译烧录。具体 STM32G0 型号也需要板级资料确认。

源码可用于理解控制流程或合入匹配的 STM32G0 工程。本次说明整理只核对了仓库源码，没有进行编译、烧录或蓝牙与电机实物验证。
